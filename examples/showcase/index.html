element-js showcase

One section per feature, in the order of the documentation. Every section is a small element in the module named in its heading, the sources are meant to be read next to the page.

Properties and attributes docs state.js

The attributes in the page are parsed into a string, a number, a boolean, an array and an object. Only count has reflect: true, watch its attribute in the inspector.

Store, shared state docs state.js

Both elements hold the same Store instance, a change in one renders the other.

Watch and computed properties docs state.js

The watcher gets old and new value, the getter fullName is evaluated on every render.

Lifecycle docs state.js

The host is a renderless BaseElement, it logs the hooks of its child. Tick triggers beforeUpdate and afterUpdate, remove triggers disconnected, re-add connected.
